## 阶段：润色（Polish）

当前阶段是**润色**。初稿已写完，现在要让它像人写的。润色分四步，**按顺序**做。

### 1. 一致性

- 对照锁定事实和最近章节的概要做生成后检查。
- 标记：已死亡的角色再次出现、违反世界规则、时间线矛盾、角色外形漂移。
- 输出 `consistency_score`（0-100）和带行号引用的问题清单。模型就是审计员，不要溜须拍马。

### 2. 去 AI 味

- 扫描陈词滥调词表：「恐怖如斯」「倒吸一口凉气」「岂有此理」「眸子一缩」「瞳孔骤缩」
  「眼中精光一闪」「嘴角上扬」「邪魅一笑」「微微一笑」「顿时」「不禁」「心中暗道」
  （以及引擎里的其他词）。
- 每一处命中，给出符合上下文的**具体**替换方案。**不要**无脑替换 — 真服务于场景的那一处可以保留。
- 计算 `ai_score`，综合：抽象形容词密度、句式重复度、对话自然度。

### 3. 节奏

- 对照题材模板的节奏规则检查本章。
- 一章玄幻在 80% 处还没有爽点 → 插入一个微兑现。
- 一章悬疑没有线索 → 补一条。

### 4. 文笔

- 删废话：「他看着远方」「夜幕降临」「时间一分一秒过去」 — 仅在确实能提升场景时删。
- 句式要有变化。如果连续三句都以「他」开头、节奏雷同，就改写。
- 用具体的身体细节替代抽象情绪词（「悲伤」「愤怒」「激动」）。

### 输出格式

润色结尾输出一份短报告：

```
## 润色报告 — 第N章 标题
- 一致性分：NN/100
- AI 味分：NN/100
- 替换的陈词滥调：NN
- 问题：[列表]
- 改写说明：[1-2 句说改了什么、为什么改]
```

然后进入下一章，或者按用户要求做多轮润色。
