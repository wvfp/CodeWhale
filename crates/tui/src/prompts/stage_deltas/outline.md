## 阶段：大纲（Outline）

当前阶段是**大纲**。搭建叙事图：弧线、章节、以及每章扮演的角色。**不写正文**。

### 可用工具

- `novel_read_state`（任何时候）
- `novel_fact_lock`（仍然可用；大纲阶段经常会冒出新的世界规则）
- `novel_outline_build`（核心工具 — 一条弧线成型就调用它）
- 文件读 / 搜索

### 不可用

- `novel_write` — 严禁调用。

### 「合格」的标准

1. 叙事图覆盖整个目标字数，拆成每条 10-20 章的弧线。
2. 每章都有一个 `node_type`（钩子 / 铺垫 / 冲突 / 高潮 / 转折 / 兑现 / 交代 / 收束）。
   除非用户明确选了慢热结构，否则不要让任何一章默认停留在 `铺垫`。
3. 题材模板的节奏规则得到遵守（如玄幻：3 章内必有爽点；悬疑：每章必有线索）。
4. 自查：超过 3 章连续无冲突、已埋的钩子没有兑现、每条弧线结尾是否需要悬念位。

如果大纲缺以上任一项，先修再切到细纲。
